README - Ejercicios de Kotlin
Descripción

Este proyecto contiene varios ejercicios desarrollados en Kotlin utilizando Programación Orientada a Objetos (POO). Los ejercicios fueron realizados con el objetivo de practicar conceptos fundamentales como clases, objetos, herencia, interfaces, encapsulamiento y polimorfismo.

Además, algunos ejemplos fueron adaptados al tema de reservas de hotel y sistemas de pagos.

Temas Aplicados
Clases y objetos
Métodos y atributos
Encapsulamiento
Herencia
Interfaces
Polimorfismo
Listas y colecciones
Validaciones
Sobrescritura de métodos (override)
Ejercicios Incluidos

1. Clase Libro

Sistema para representar libros con:

Título
Autor
Año de publicación
Número de páginas

Funciones:

Mostrar información
Verificar si el libro es antiguo o reciente

2. ProductoInventario

Sistema de inventario con:

Código
Nombre
Precio
Stock

Funciones:

Consultar precio y stock
Aumentar stock
Disminuir stock
Cambiar precio

Validaciones:

Precio no negativo
Stock no menor a cero

3. Vehículos

Jerarquía de clases:

Vehículo
Auto
Motocicleta

Conceptos aplicados:

Herencia
Sobrescritura de métodos

4. Métodos de Pago

Sistema de pagos utilizando interfaces.

Métodos implementados:

Pago en efectivo
Pago con tarjeta
Pago por transferencia

Conceptos aplicados:

Interfaces
Polimorfismo

5. Sistema de Biblioteca

Sistema para gestionar préstamos de libros.

Funciones:

Registrar libros
Prestar libros
Devolver libros
Buscar libros
Listar disponibles

Validaciones:

No prestar libros ya prestados
No devolver libros no prestados
